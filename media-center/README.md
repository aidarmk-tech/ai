# LampMedia — самостоятельный медиацентр Android TV

Отдельный APK `com.lampplayer.tv.center`, устанавливается рядом с LampPlayer. Рабочее название — LampMedia.

## Первая версия

- Нативный интерфейс с управлением пультом: каталог TMDB, фильмы, сериалы, поиск и карточки с описанием/актёрами.
- Сезоны и эпизоды → поиск раздач JacRed/Torznab → выбор файла → встроенный плеер.
- Встроенный TorrServer: запускается из установленной библиотеки APK, отдельная установка сервера не требуется.
- Избранное, история, продолжение по сохранённой позиции и автопереход при подтверждённом списке эпизодов.
- Настройки звука, субтитров и движка используют готовый LampPlayer.
- Свой канал обновлений `media-center`, независимый от `auto` плеера.

В разделе «Источники» укажи свой JacRed (адрес сервера) или полный Torznab API URL и ключ, если нужен.
Публичные адреса источников не предустановлены. Можно открыть свою magnet-ссылку/ссылку на .torrent из карточки.

## Улучшенный интерфейс и управление

- Главная: фоновый баннер, отдельные ряды фильмов/сериалов, карточки продолжения с позицией и прогрессом.
- Активный раздел выделен в боковом меню. Вправо переводит фокус к первому действию экрана.
- Назад восстанавливает предыдущую карточку, горизонтальный ряд и прокрутку без повторного поиска.
- В карточке сериала сезоны и просмотр идут раньше описания/актёров; эпизоды слева, описание выбранного эпизода справа.
- Отдельная история; удержание ОК удаляет запись из истории, на постере каталога — переключает избранное.
- В форме источника доступен пробный запрос. Неправильный API, HTML и ошибки ключа не считаются успешным ответом.
- В настройках движка доступны запуск/остановка и кэш 32/64/128/256 МБ. Другие настройки TorrServer сохраняются.
  Изменение кэша переподключает раздачи; применяется между просмотрами. Размер кэша не равен всей памяти приложения.
- Уход с экрана отменяет HTTP-запрос. Фоновые картинки загружаются с ограниченным размером.

UI-проверки включают реальные D-pad события, переход каталог → сериал → сезон → назад и Android-рендеры четырёх экранов.
Проверка на Android 34 также меняет размер кэша через API упакованного движка и читает его обратно.

## Встроенный движок и исходный код

TorrServer MatriX.148, GPL-3.0. Лицензия включена в APK и доступна в настройках.
Исходный код соответствующей версии: https://github.com/YouROK/TorrServer/archive/refs/tags/MatriX.148.tar.gz
Проверенные SHA-256 и архитектуры зафиксированы в `engine.lock.json`.
`prepare_engine.py` загружает официальные бинарные релизы при сборке, проверяет хеш/ELF ABI и помещает их в jniLibs.
Бинарники не скачиваются приложением и не хранятся в Git. Движок привязан к 127.0.0.1, данные — в приватном каталоге приложения.
Работающий процесс сопровождается уведомлением с кнопкой остановки.

## Сборка

```sh
python media-center/prepare_engine.py
cd lampa-player-native
gradle testDebugUnitTest assembleDebug -PmediaCenter=true -PverCode=1 -PverName=0.1.1
```

CI собирает ARM APK, запускает тесты интерфейса/парсеров/истории и отдельный smoke-test
упакованного x86_64 движка на Android 34. Публикация выполняется только после обеих проверок.

Это первая рабочая версия. Проверка на конкретном ARM-телевизоре, оптимизация размера/памяти,
профили пользователей, Trakt, голосовой поиск и IPTV остаются следующими этапами; полного паритета с Flux пока нет.
