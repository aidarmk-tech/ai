# Прозрачный удалённый мониторинг экрана

Небольшой инструмент, чтобы **удалённо смотреть, что происходит на экране вашего
компьютера** — с телефона или другого устройства через обычный браузер.

Инструмент **специально сделан прозрачным (не скрытным)**:

- при запуске выводит баннер в консоль;
- держит **видимый значок в системном трее** — «Мониторинг ВКЛЮЧЕН» (зелёная точка);
- при подключении зрителя пишет запись в лог и показывает уведомление на рабочем столе;
- доступ к странице закрыт **паролем**.

> ⚠️ Ставьте только на компьютер, которым владеете. Если машиной пользуются
> другие люди — предупредите их, что ведётся наблюдение. Скрытая слежка за
> человеком без его ведома во многих странах незаконна.

## Что делает

Захватывает экран (`mss`), кодирует кадры в JPEG и отдаёт их как MJPEG-поток
на веб-страницу, защищённую HTTP Basic-паролем. Видео идёт «вживую» в браузере.

## Установка

Нужен Python 3.9+.

```bash
cd remote-monitor
python -m venv venv
# Windows:  venv\Scripts\activate
# macOS/Linux:  source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
# Пароль лучше передавать через переменную окружения, а не в командной строке:
export MONITOR_PASSWORD="ваш-пароль"        # Windows: set MONITOR_PASSWORD=...
python server.py
```

При старте покажется адрес вида `http://192.168.1.50:8000/`. Откройте его на
телефоне (в той же сети), введите **любой логин** и заданный пароль.

### Параметры

| Флаг | Значение по умолчанию | Описание |
|------|----------------------|----------|
| `--port` | `8000` | Порт веб-сервера |
| `--password` | — | Пароль (лучше через `MONITOR_PASSWORD`) |
| `--fps` | `5` | Кадров в секунду |
| `--quality` | `60` | Качество JPEG (1–95) |
| `--monitor` | `1` | Экран: `1` — основной, `0` — все вместе |
| `--scale` | `1.0` | Масштаб кадра, напр. `0.5` — вдвое меньше (экономит трафик) |
| `--no-tray` | — | Не показывать значок в трее |

Пример «поэкономнее» для мобильного интернета:

```bash
python server.py --fps 3 --quality 45 --scale 0.6
```

## Доступ из интернета (не только из домашней сети)

**Windows, в один клик:** запустите `START.bat` — он сам поставит компоненты,
скачает `cloudflared`, свернётся в панель задач, поднимет мониторинг и туннель
и сохранит публичную `https`-ссылку в файл `LINK.txt` (доступ без пароля).

Вручную: по умолчанию поток виден только в вашей локальной сети. Чтобы смотреть
извне, **не** пробрасывайте порт напрямую (небезопасно). Используйте туннель, например:

```bash
# Cloudflare Tunnel (бесплатно, https-адрес):
cloudflared tunnel --url http://127.0.0.1:8000
```

или Tailscale — тогда компьютер и телефон будут в одной приватной сети.

## Автозапуск

Готовые установщики для всех трёх ОС — в папке [`autostart/`](autostart/README.md):

```bash
bash autostart/linux-systemd/install.sh                                  # Linux
bash autostart/macos-launchd/install.sh                                  # macOS
powershell -ExecutionPolicy Bypass -File .\autostart\windows\install.ps1 # Windows
```

Скрипт спросит пароль, пропишет автозапуск при входе в систему и сразу
запустит мониторинг. Подробности и удаление — в [autostart/README.md](autostart/README.md).

## Безопасность

- Пароль обязателен; сравнение — через `secrets.compare_digest`.
- Для доступа из интернета используйте HTTPS-туннель (см. выше).
- Задавайте длинный пароль; не храните его в командной строке (виден в списке
  процессов) — используйте переменную окружения.

## Ограничения

- Захват экрана требует прав на доступ к экрану (на macOS — разрешение
  «Запись экрана» в настройках приватности).
- Это мониторинг **экрана**. Веб-камера и звук сюда не входят.
